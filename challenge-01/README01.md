# Challenge 01 - Lista de contactos (React)

## Cómo usarlo
1. Crea el proyecto: `npm create vite@latest` (elige React).
2. Reemplaza `src/App.jsx` por el de esta carpeta.
3. Copia la carpeta `src/components` dentro de tu `src`.
4. `npm install` y `npm run dev` para probar.

## Qué cumple del enunciado
- Loader al iniciar (simulado con `setTimeout` en `useEffect`).
- Carga inicial de contactos.
- Agregar contacto (nombre y teléfono).
- Eliminar contacto.
- App dividida en componentes: Loader, ContactList, ContactItem, AddContactForm.
